# The Reading Machine

An interactive reading prototype featuring Eaty, highlighting and comments, reading tools, saved reading history, and a finishing animation.

## Try the website

[Open the published Reading Machine](https://kkelvin-li.github.io/Reading_Machine/).

You can click the Open Demo PDF to access my thesis and play with it. You can also upload your own pdf, but a lot of functions would not work properly. 

If you have any issue play with the website such as sound not playing, too slow to load or any other issues, you could also watch the demo video.
